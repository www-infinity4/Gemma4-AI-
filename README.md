# Gemstone Mountain + Gemma Gem Guide

A lightweight, phone-first gateway to Verzazio wholesale loose gemstones on eBay and Etsy, with public contact listings for New York and Sicily.

## What works on GitHub Pages

- Direct links to the verified `VERZAZIO Jewelers` eBay store and `Verzazio` Etsy shop
- Search cards for mixed lots, amethyst, citrine, rough stones, and diamond parcels
- Phone-friendly office, map, marketplace-message, and shop buttons
- An instant Gemma Gem Guide covering lots, treatments, testing, and buying checks
- Optional connection to a compatible local Gemma/llama.cpp server at `http://127.0.0.1:8080/v1`

The built-in guide works without a login, API key, server, or model download. It uses a focused local knowledge map and never pretends that it is the full Gemma model. If a compatible local engine is running, the guide can switch to generated Gemma replies.

## Important boundaries

GitHub Pages hosts the interface but cannot run model weights. Marketplace stock, prices, feedback, ratings, and policies can change. Contact details are from public business listings and should be confirmed before an in-person visit. Gem identity or investment value should be independently verified when it matters.
